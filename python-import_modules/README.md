# Python - Import & Modules

Importing functions from other files, using modules, and handling command line arguments in Python.

## Files

| File | Description |
| ---- | ----------- |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `add_0.py` | Defines the addition function used by `0-add.py` |
| `1-calculation.py` | Imports the four operations from `calculator_1.py` and prints each result |
| `calculator_1.py` | Defines `add`, `sub`, `mul` and `div` |
| `2-args.py` | Prints the number of command line arguments and lists them |
