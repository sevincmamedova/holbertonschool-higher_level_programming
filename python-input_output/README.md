# Python - Input/Output

Reading and writing files, and serializing objects with JSON.

## Files

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Reads a UTF8 text file and prints it to stdout |
| `1-write_file.py` | Writes a string to a UTF8 text file and returns the character count |
| `2-append_write.py` | Appends a string at the end of a UTF8 text file |
