The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class from the module:

    >>> MyList = __import__('1-my_list').MyList

``MyList`` inherits from ``list``:

    >>> issubclass(MyList, list)
    True

An instance behaves like a regular list:

    >>> my_list = MyList()
    >>> my_list
    []
    >>> isinstance(my_list, list)
    True

Building the list of the example, then printing it sorted:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is left untouched:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

A list can also be built from an existing one:

    >>> my_list = MyList([7, 1, 9])
    >>> my_list.print_sorted()
    [1, 7, 9]

An empty list prints an empty list:

    >>> MyList().print_sorted()
    []

A list already sorted stays in the same order:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

A list sorted in reverse is turned around:

    >>> MyList([3, 2, 1]).print_sorted()
    [1, 2, 3]

Negative numbers come first:

    >>> MyList([2, -3, 0, -1]).print_sorted()
    [-3, -1, 0, 2]

Repeated values are all kept:

    >>> MyList([4, 4, 1, 4]).print_sorted()
    [1, 4, 4, 4]

A list with a single element is printed as is:

    >>> MyList([98]).print_sorted()
    [98]

``print_sorted`` takes no argument other than ``self``:

    >>> MyList([1, 2]).print_sorted(3)
    Traceback (most recent call last):
    TypeError: print_sorted() takes 1 positional argument but 2 were given
